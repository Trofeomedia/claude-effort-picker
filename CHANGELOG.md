# Changelog

## 0.2.0

- Mouse wheel over the Claude panel: Ctrl+Alt+wheel steps the effort level up or down, Ctrl+Shift+wheel steps the model (Sonnet, Opus, Fable).

## 0.1.0

- First release: the Claude Code model pill shows only the model, a separate button next to it shows the effort level and opens a menu to change it.
- Re-applies itself automatically after Claude Code updates (asks you to reload the window).
- Commands to re-apply and to remove; uninstalling restores Claude Code to its original state.
